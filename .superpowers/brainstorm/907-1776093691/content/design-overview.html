改動 3 — B2 備用匯出（複雜流程用）

流程：前端截圖 → 嵌入 PPTX
1. 前端 Vue Flow 畫布 → html2canvas 截成 PNG (高解析度)
2. PNG base64 POST 到新 endpoint POST /flowchart/export-pptx-image
3. 後端把圖片貼滿整張 slide，加上標題文字框
4. 前端 UI 新增切換：「可編輯圖形」vs「高保真圖片」

⚠️ 圖片模式下 PPTX 內的形狀不可編輯，但外觀 100% 還原畫布

執行順序建議： 改動 1（skill.md）→ 改動 2（PPTX 修正）→ 改動 3（B2 備用）
每個改動可獨立測試，不互相依賴。
