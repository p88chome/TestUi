改善流程圖的兩條主線

AI 品質（A）和 PPTX 匯出（B）各有不同的改法。選你偏好的方向。

🧠 主線 A：AI 生成品質

A1

搬進 skill.md + 豐富 prompt（推薦）

把兩個 prompt（DECOMPOSE + RENDER）移到 flowchart_generator/skill.md，加入：
• 詳細的角色定義與範例 JSON
• 內控流程圖的業務規則（COSO 框架、泳道命名規範）
• Few-shot 範例（2-3 個標準案例）
• 不改 code 即可迭代 prompt

優點

  • 快速可見效果
  • prompt 可在前端即時編輯
  • 為 tenant 差異化打基礎

缺點

  • skill.md 會變很長
A2

加中間驗證層（self-critique）

在現有兩步（拆解 → 渲染）之間加一步驗證：
• Step 1：拆解成步驟 JSON
• Step 1.5：AI 自我審查（是否每條流程都有終點？決策點分支完整？）
• Step 2：修正後再渲染

優點

  • 結構錯誤大幅減少
  • 決策點漏 branch 問題消失

缺點

  • 多一次 LLM call，慢 2-4 秒
  • 需多寫一段 API 邏輯

📊 主線 B：PPTX 匯出品質

B1

修 python-pptx 渲染邏輯（推薦）

現有程式碼有幾個明顯 bug 和缺陷，直接修：
• 修 oval shape 的 double-add bug
• 加泳道背景色（每個 lane 淡色底）
• 改用拓撲排序決定節點上下位置（依連線順序，非堆疊）
• connector 改 elbow 型（彎折箭頭），避免穿越節點
• 換 Deloitte 配色

優點

  • 改動範圍集中，風險低
  • 效果立竿見影

缺點

  • python-pptx connector routing 有限制，複雜流程仍難看
B2

前端截圖 → 嵌入 PPTX

讓 Vue Flow 畫布用 html2canvas 截成高解析度圖片，後端直接把圖片嵌進 PPTX slide。
匯出的 PPTX = 圖片（不可編輯節點，但外觀 100% 還原畫布效果）

優點

  • 外觀最好看（前端 CSS 樣式完整保留）
  • 後端邏輯極簡

缺點

  • PPTX 裡的圖形無法編輯（只是圖片）
  • 使用者若要修改需回平台

💡 我的推薦：A1 + B1 組合 — 先讓 skill.md 讓 AI 更準，同時修 PPTX 渲染 bug 加泳道背景色。效果快，風險低。
