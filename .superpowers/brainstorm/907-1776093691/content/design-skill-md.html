設計細節 1/3：skill.md 結構

這個檔案是讓 AI「變聰明」的核心，分三個區塊

app/skills/flowchart_generator/skill.md 完整結構
--- name: flowchart_generator description: 將內控 SOP 文件轉換成泳道流程圖（nodes/edges + PPTX） category: enterprise keywords: [flowchart, 流程圖, SOP, 內控, swimlane] input_schema: doc_text: string # 原始文件內容 additional_context: string # 使用者補充說明（可空） modification: string # 對話修改指令（可空） --- # === DECOMPOSE PROMPT === 你是資深內部控制顧問，專精 COSO 框架與 ISO 9001... （詳細拆解規則） # === RENDER PROMPT === 你是流程圖繪製專家，依照以下規範輸出 nodes/edges... （詳細渲染規則） # === FEW-SHOT EXAMPLES === ## 範例 1：採購申請流程 輸入：「申請人填寫申請單後，送部門主管審核...」 輸出：{ "steps": [...], "nodes": [...], "edges": [...] } ## 範例 2：費用報帳流程 ... # === BUSINESS RULES === - 泳道命名優先用「職位」而非「部門」 - 決策點文字必須是問句（結尾加「？」） - 每條流程必須有且只有一個 start / 一個 end - generates_document 只填「正式表單名稱」，不填步驟動作
